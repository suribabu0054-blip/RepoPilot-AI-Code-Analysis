## 🎥 Production Notes

### Visual Guidelines

1. **Screen Recording**:
   - Use 1920x1080 resolution
   - Enable cursor highlighting
   - Smooth transitions between tabs
   - Use zoom effects for important details

2. **Text Overlays**:
   - Use bold, sans-serif font (e.g., Montserrat, Inter)
   - High contrast colors (white text on dark background)
   - Animate text entries (fade in, slide up)
   - Keep overlays brief and impactful

3. **Pacing**:
   - Quick cuts to maintain energy
   - Pause briefly on key findings (2-3 seconds)
   - Use smooth transitions (fade, slide)
   - Match voiceover timing precisely

### Audio Guidelines

1. **Voiceover**:
   - Clear, enthusiastic delivery
   - Moderate pace (not too fast)
   - Emphasize key phrases ("10 seconds", "60% faster")
   - Professional microphone quality

2. **Background Music** (Optional):
   - Subtle, upbeat tech music
   - Low volume (don't overpower voiceover)
   - Fade out during key moments
   - Energetic but not distracting

3. **Sound Effects** (Optional):
   - Subtle "whoosh" for transitions
   - "Ding" for completed agents
   - "Click" sounds for button presses

### Editing Tips

1. **Timing**:
   - Stick strictly to 2-minute limit
   - Each section should hit its time mark
   - Practice voiceover multiple times
   - Use a teleprompter if needed

2. **Emphasis**:
   - Highlight vulnerabilities in red
   - Use green checkmarks for completed agents
   - Zoom in on important metrics
   - Circle or box key information

3. **Branding**:
   - Show IBM watsonx.ai logo prominently
   - Include Granite model badge
   - Display LangGraph architecture
   - Consistent color scheme (blue/green)
